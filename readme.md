
# Python POO

Um projeto dedicado ao reforço das **bases de Programação Orientada a Objetos (POO) em Python**.

## Objetivo

Consolidar conceitos fundamentais de POO através de exemplos práticos e exercícios, incluindo:

- Classes e Objetos
- Herança
- Encapsulamento
- Polimorfismo
- Abstração
- Métodos e Atributos

## Como usar

Clone o repositório e explore os exemplos de código para aprofundar seu conhecimento em POO.

## Tecnologia

- Python 3.x

## Créditos

- Todos os exercícios foram tirados do Curso em Vídeo, Gustavo Guanabara.
